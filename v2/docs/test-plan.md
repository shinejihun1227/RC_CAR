# v2 검증 순서

1. 조종기에서 ADC와 버튼 입력을 시리얼로 확인한다.
2. 양쪽 ESP32의 MAC 주소를 기록한다.
3. 조종기→차량 단방향 ESP-NOW 수신을 확인한다.
4. 조이스틱 중립·전후·좌우에서 명령값을 확인한다.
5. 조종기 전원을 껐을 때 300 ms 안에 차량이 정지하는지 확인한다.


## 전진 감시 추가 시험

- 201mm, 200mm, 199mm 부근에서 전진 허용·차단을 확인한다. 센서 오차가 있으므로 실제 출력값도 기록한다.
- 주행 중 센서 갱신이 끊기면 전진이 차단되는지 확인한다.
- 가까운 장애물에서 후진·제자리 회전이 가능한지 확인한다.
