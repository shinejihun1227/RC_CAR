# v2 — 사용자 피드백과 원격 제어 확장

v1 센서 입력을 바탕으로 사용자가 RC카 상태를 확인하고 제어할 수 있게 만듭니다.

## 추가 기능 후보

- ESP32 Wi-Fi 웹 제어 페이지
- 진동모터 알림
- 저출력 레이저모듈 상태 표시
- 센서 상태와 주행 명령의 연동

## 안전 기준

- 진동모터와 레이저 전원은 GPIO에 직접 연결하지 않고 MOSFET으로 제어한다.
- 레이저를 사람 또는 반사면을 향하지 않는다.
- 원격 연결이 끊기면 모터를 정지하는 안전 동작을 추가한다.

`docs/`, `firmware/`, `hardware/` 폴더는 v2 기능을 실제로 시작할 때 추가합니다.
