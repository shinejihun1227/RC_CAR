# v1 — IMU 자세 추정 RC카

v0의 기본 주행이 완료된 뒤 시작합니다. 이 버전에서는 RC카의 기울기와 진행 방향 변화를 측정합니다.

## 목표

- IMU에서 가속도계·자이로스코프·지자기계 데이터를 읽는다.
- 센서 융합 결과를 이용해 Roll, Pitch, Yaw를 표시한다.
- 주행 중 과도한 기울기를 감지해 경고 또는 감속 조건으로 사용한다.

## 권장 부품

- **BNO085 또는 BNO086 브레이크아웃 모듈**: 9축 IMU와 센서 융합 기능을 제공하는 모듈
- ESP32와 3.3 V I2C로 연결

## 배치 원칙

- IMU는 차체의 중심에 가깝고 수평인 위치에 고정한다.
- 모터, 모터 전선, TB6612FNG, DC-DC 컨버터와 가능한 멀리 둔다.
- 최종 조립 상태에서 지자기 보정을 수행한다. 모터 자계 때문에 Yaw는 특히 영향을 받을 수 있다.

## 완료 기준

- 정지 상태에서 Roll·Pitch 값이 안정적이다.
- 차체를 기울이면 Roll 또는 Pitch 변화가 확인된다.
- 회전 시 Yaw 변화가 확인된다.
- 원시 센서 값과 자세 추정 값을 시리얼 모니터로 출력한다.

`docs/`, `firmware/`, `hardware/` 폴더는 v1 구현을 시작할 때 추가합니다.
