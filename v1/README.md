# v1 — 센서 확장 RC카

v0의 기본 주행이 완료된 뒤 시작합니다. 이 버전에서는 RC카가 주변 또는 사용자의 입력을 읽을 수 있게 만듭니다.

## 추가 기능 후보

- FSR406 압력센서: 아날로그 입력과 임계값 판단
- SHTC3: 온도·습도 수집
- I2C MUX: 여러 I2C 장치 또는 동일 주소 센서 확장
- 아날로그 MUX: 다수의 아날로그 센서 입력 확장

## 시작 전 확인

- v0의 모터·전원 회로가 안정적으로 동작하는가?
- 추가 센서 전원은 3.3 V와 로직 레벨에 맞는가?
- 각 기능을 별도 Issue로 분리했는가?

`docs/`, `firmware/`, `hardware/` 폴더는 v1 기능을 실제로 시작할 때 추가합니다.
