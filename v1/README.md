# v1 — 거리 감지와 안전 정지 RC카

v0의 기본 주행이 완료된 뒤 시작합니다. 이 버전에서는 전방 장애물까지의 거리를 읽고, 충돌을 줄이기 위한 안전 동작을 추가합니다.

## 목표

- 전방 거리 센서로 장애물 거리를 주기적으로 측정한다.
- 거리 임계값 안에 들어오면 경고 상태를 출력한다.
- 매우 가까운 거리에서는 전진 명령을 차단하고 모터를 정지한다.

## 권장 부품

- **VL53L1X ToF 거리 센서 모듈**: ESP32와 3.3 V I2C로 연결하는 전방 거리 센서
- 필요하면 측면 센서를 추가하되, I2C 주소가 중복될 때만 I2C MUX를 사용한다.

## 완료 기준

- 시리얼 모니터에 거리(mm 또는 cm)가 일정 주기로 출력된다.
- 경고 거리와 정지 거리를 상수로 조정할 수 있다.
- 정지 거리 이내에서는 전진 명령이 무시되고 RC카가 멈춘다.

## 권장 초기 임계값

- 경고: 50 cm
- 정지: 20 cm

실제 주행 속도와 제동 거리에 맞춰 실험 후 조정한다.

`docs/`, `firmware/`, `hardware/` 폴더에 v1의 실습 자료를 모아 둡니다.

## 실습 파일 순서

1. [공통 라이브러리 폴더](../library/README.md)에서 [VL53L1X 설치 문서](../library/vl53l1x-pololu.md)를 따라 설치한다.
2. `firmware/01_distance_read`로 센서 단품을 확인한다.
3. `firmware/02_safety_stop`으로 기본 주행에 안전 정지를 통합한다.
