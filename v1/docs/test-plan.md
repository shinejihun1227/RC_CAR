# v1 검증 순서

1. `01_distance_read`로 거리 출력이 정상인지 확인한다.
2. 1 m, 50 cm, 20 cm 물체에서 출력값을 기록한다.
3. `02_safety_stop`에서 전진 중 20 cm 이내 장애물을 놓는다.
4. 정지 후 후진과 회전은 가능한지 확인한다.
5. 센서 케이블을 분리했을 때 차량이 정지하는지 확인한다.


## 전진 감시 추가 시험

- 201mm, 200mm, 199mm 부근에서 전진 허용·차단을 확인한다. 센서 오차가 있으므로 실제 출력값도 기록한다.
- 주행 중 센서 갱신이 끊기면 전진이 차단되는지 확인한다.
- 가까운 장애물에서 후진·제자리 회전이 가능한지 확인한다.
- f를 한 번만 입력하고 추가 키 입력 없이 장애물을 접근시킨다. 정지 후 장애물을 치워도 새 f 명령 전에는 재출발하지 않아야 한다.
