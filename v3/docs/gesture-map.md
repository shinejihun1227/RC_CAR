# v3 제스처와 명령

| 입력 | 단품 gesture_map_test | 통합 controller_bmi270 |
|---|---|---|
| 중립 | 두 각도 절댓값이 8° 미만이면 STOP | 각 축 절댓값이 8° 미만이면 해당 축 명령 0 |
| Pitch 양수/음수 | 임계값을 넘으면 FORWARD/BACKWARD | 전후진 세기를 -255~255로 변환 |
| Roll 양수/음수 | Pitch가 우선 조건에 없으면 RIGHT/LEFT | 조향 세기를 -255~255로 변환 |
| 두 축 기울임 | 단일 문자열 명령으로 표시 | 전후진과 조향을 동시에 보냄 |
| 정지 버튼 | 단품 예제에는 없음 | emergencyStop 전송 |

통합 조종기는 부팅 시 100회 평균으로 중립을 저장하고 최대 명령 각도를 35°로 사용한다. 단품 예제에는 같은 중립 보정이 없다. 현재 Roll/Pitch는 가속도로 계산하며 자이로 융합이나 절대 Yaw는 구현하지 않는다.

실물 센서의 장착 방향과 손 기울기 부호를 먼저 비교한다.
