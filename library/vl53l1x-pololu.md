# VL53L1X by Pololu

## 사용하는 곳

- v1 `01_distance_read`
- v1 `02_safety_stop`
- v2 차량 수신기
- v3 차량 수신기 (v2 코드 재사용)
- v4 차량 수신기

## 설치

1. Arduino IDE에서 `스케치 > 라이브러리 포함하기 > 라이브러리 관리`를 연다.
2. `VL53L1X`를 검색한다.
3. 제작자가 `Pololu`인 **VL53L1X**를 설치한다.

## 확인

`v1/firmware/01_distance_read/01_distance_read.ino`를 먼저 업로드해 거리 값이 출력되는지 확인한 뒤 안전 정지 실습으로 넘어갑니다.
