# 라이브러리 안내

프로젝트 전체에서 사용하는 Arduino 라이브러리와 설치 방법을 이 폴더에 모읍니다.
각 버전의 실습을 시작하기 전에 필요한 문서만 확인합니다.

| 라이브러리 또는 기능 | 문서 | 사용하는 버전 |
| --- | --- | --- |
| ESP32 보드 패키지 | [esp32-board-package.md](esp32-board-package.md) | v0, v1, v2, v3, v4 |
| VL53L1X ToF 센서 | [vl53l1x-pololu.md](vl53l1x-pololu.md) | v1, v2, v4 차량 |
| ESP-NOW | [esp-now.md](esp-now.md) | v2, v3, v4 |
| BMI270 IMU | [bmi270-sparkfun.md](bmi270-sparkfun.md) | v3 조종기 |

`WiFi.h`, `esp_now.h`, `Wire.h`는 ESP32 보드 패키지에 포함되어 있어 별도로 설치하지 않습니다.
