# SparkFun BMI270 Arduino Library

## 사용하는 곳

- v3 `00_bmi270_read`
- v3 `01_gesture_map_test`
- v3 `controller_bmi270`

## 설치

1. Arduino IDE에서 `스케치 > 라이브러리 포함하기 > 라이브러리 관리`를 연다.
2. `SparkFun BMI270`을 검색한다.
3. 제작자가 `SparkFun Electronics`인 **SparkFun BMI270 Arduino Library**를 설치한다.

## 확인

`v3/firmware/00_bmi270_read/00_bmi270_read.ino`로 가속도와 자이로 값이 출력되는 것을 확인한 뒤 제스처 실습을 진행합니다.
