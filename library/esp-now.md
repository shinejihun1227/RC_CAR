# ESP-NOW

## 사용하는 곳

- v2 조이스틱 조종기와 차량
- v3 BMI270 제스처 조종기와 차량

## 설치 여부

별도 라이브러리 설치는 필요 없습니다. `esp_now.h`와 `WiFi.h`는 [ESP32 보드 패키지](esp32-board-package.md)에 포함됩니다.

## 사전 확인

1. 차량과 조종기 모두 ESP32 보드 패키지를 설치한다.
2. `v2/firmware/00_print_mac`을 각 보드에 업로드해 MAC 주소를 기록한다.
3. 송신 코드의 `vehicleMac` 배열에 차량 ESP32의 MAC 주소를 입력한다.
4. 통신 실습은 v2의 송신·수신 테스트 코드부터 진행한다.
