# RC Car v0 블록 다이어그램

```text
              AA 알카라인 배터리 4개
                    |
          +---------+----------+
          |                    |
   TB6612FNG VM        5 V 벅-부스트 컨버터
          |                    |
     좌·우 모터           ESP32 개발보드
                              |
                           GPIO
                              |
                    Wi-Fi 제어(다음 단계)
```

## 제어 흐름

```text
사용자 명령 → ESP32 → TB6612FNG → 좌·우 모터 → RC카 이동
```

ESP32와 TB6612FNG의 GND는 반드시 공통으로 연결한다. TB6612FNG의 VCC와 센서 전원은 ESP32의 3.3 V 핀을 사용한다.
