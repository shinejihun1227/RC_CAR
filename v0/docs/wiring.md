# ESP32와 TB6612FNG 배선

아래 핀은 예시이며, 사용 중인 ESP32 보드와 충돌하지 않는지 확인한 뒤 변경할 수 있습니다.

| TB6612FNG | ESP32 / 전원 | 설명 |
| --- | --- | --- |
| VCC | 3.3 V | 드라이버 로직 전원 |
| VM | AA 배터리 4개 팩 (+) | 모터 전원, 스위치 뒤에서 연결 |
| GND, PGND | 공통 GND | ESP32·모터 전원과 공통 |
| STBY | GPIO 25 | HIGH일 때 드라이버 활성화 |
| AIN1 / AIN2 | GPIO 26 / GPIO 27 | 왼쪽 모터 방향 |
| PWMA | GPIO 14 | 왼쪽 모터 PWM |
| BIN1 / BIN2 | GPIO 32 / GPIO 33 | 오른쪽 모터 방향 |
| PWMB | GPIO 13 | 오른쪽 모터 PWM |
| A01 / A02 | 왼쪽 모터 | 모터 단자 |
| B01 / B02 | 오른쪽 모터 | 모터 단자 |

AA 배터리팩은 TB6612FNG의 VM에 직접 연결하고, 같은 배터리팩을 5 V 벅-부스트 컨버터 입력에도 연결한다. 컨버터의 5 V 출력은 ESP32의 `5V` 또는 `VIN` 핀에 연결한다. 모든 GND는 공통으로 연결한다.

모터 방향이 반대면 모터의 두 선을 서로 바꾸거나 코드의 방향 상수를 반전한다.
