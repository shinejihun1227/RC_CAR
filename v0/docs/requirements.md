# RC Car v0 요구사항

## 사용자 시나리오

사용자는 ESP32가 제공하는 제어 명령으로 RC카를 전진, 후진, 좌회전, 우회전, 정지할 수 있다.

## 기능 요구사항

- 2개의 DC 기어드모터를 독립적으로 제어한다.
- 모터 방향을 반전할 수 있다.
- 정지 명령에서는 두 모터를 모두 정지한다.
- 전원을 켰을 때 모터가 임의로 움직이지 않는다.
- 향후 Wi-Fi 제어와 센서 기능을 추가할 수 있도록 핀 배치를 문서화한다.

## 비기능 요구사항

- ESP32 전원과 모터 전원은 분리된 DC-DC 출력으로 공급한다.
- 모든 모듈의 GND는 공통으로 연결한다.
- 모터 드라이버는 ESP32 GPIO에서 직접 모터 전류를 끌어오지 않는다.

## v0 범위 밖

- 자율주행, 카메라, LiDAR
- FSR406, SHTC3, I2C MUX, 아날로그 MUX
- 레이저모듈과 진동모터

이 기능들은 기본 주행을 검증한 후 별도 Issue와 브랜치에서 추가한다.
