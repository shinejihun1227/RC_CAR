# 구매 정보 (market)

이 폴더는 버전별로 **새로 구매해야 하는 부품**과 AliExpress에서 찾을 때 쓸 검색어를 관리합니다. 이전 버전에서 이미 구매한 부품은 다시 구매하지 않습니다.

## 링크 작성 원칙

AliExpress 판매 상품은 판매자·재고·규격이 자주 바뀌므로, 링크를 추가하기 전 아래를 반드시 확인합니다.

1. 전압, 핀 배열, 실제 치수를 문서의 선택 기준과 비교한다.
2. 차량 전원은 충전하지 않는 AA 알카라인 배터리 4개와 4칸 AA 홀더를 사용한다.
3. 모터 드라이버는 `TB6612FNG` 표기가 있고, L298N이 아닌지 확인한다.
4. 확인한 상품 URL은 각 표의 `확인한 상품 URL` 칸에 기록한다.

현재 이 저장소에는 판매자나 재고를 검증하지 않은 링크를 넣지 않습니다. 표의 `AliExpress 검색어`를 그대로 검색한 뒤, 실제 구매할 상품 URL을 기록해 사용합니다.
