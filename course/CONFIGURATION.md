# 실습 장비별 설정

아래 값은 수업 전에 장비에서 확인한다. 저장소의 기본값을 실제 보정 결과로 간주하지 않는다.

| 항목 | 위치 | 설정 방법 |
|---|---|---|
| ESP32 보드·포트 | Arduino IDE | ESP32 Dev Module과 해당 USB 포트 선택 |
| 차량 MAC | v2 송신 시험·조이스틱, v3 BMI270 송신 코드의 vehicleMac | v2/firmware/00_print_mac으로 차량 STA MAC 확인 |
| 조이스틱 중심·방향 | v2 controller_joystick | 기본 중심 2048, 데드존 120. 손을 떼었을 때 0인지 확인 |
| BMI270 중립 | v3 controller_bmi270 | 부팅 시 100회 평균 동안 조종기를 움직이지 않음 |
| 기울기 크기 | v3 controller_bmi270 | 기본 데드존 8°, 최대 명령 각도 35° |
| 모터 방향 | 버전별 모터 함수와 배선 | FL/FR/RL/RR 또는 좌/우 한 개씩 확인 |
| 바퀴 1회전당 펄스 | v4 스케치 3개의 PULSES_PER_WHEEL_REV | CHA 상승 에지 기준으로 실측. 기본값 1.0은 미보정 표시 |
| PID·trim | v4 속도 튜닝·통합 수신기 | 같은 장비에서 측정한 계수와 모터별 보정값을 두 코드에 반영 |
| 차체·홀·간섭 치수 | hardware/fusion360 | 실제 모터·보드·홀더·바퀴를 측정 |

## 전진 안전 판단

v1 안전 주행과 v2·v4 차량 수신기는 거리 200mm 이하에서 전진을 차단한다. 유효한 거리값이 없거나 최근 측정이 250ms 넘게 갱신되지 않아도 전진을 차단한다. 후진·제자리 회전은 장애물에서 빠져나오는 동작으로 허용한다.

v1의 500mm 이내 경고는 시리얼 알림이다. 자동 감속 기능은 기본 코드에 포함하지 않는다. v2·v4는 수신 중단을 300ms 기준으로 판단하고 정지 버튼 명령도 우선 처리한다. 실제 정지 지연은 루프 실행 시간, 센서·I²C 상태와 실물 관성의 영향을 받으므로 테스트 계획대로 측정한다.

## 엔코더 실측

00_encoder_read는 500ms 구간별 펄스를 출력한다. 바퀴를 한 바퀴 돌리는 동안의 구간 펄스를 더해 출력축 한 바퀴의 PPR을 구한다. 마지막 구간을 빠뜨리지 않도록 정지 후 출력까지 확인한다.

CHA만 읽으므로 실제 회전 방향은 측정하지 않는다. 회전 방향은 모터에 내린 명령을 기준으로 사용한다. CHB를 이용한 방향 측정은 확장 실습이다.
