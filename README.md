# RC_CAR

ESP32로 만드는 2WD Wi-Fi RC카 프로젝트입니다. 이 저장소는 버전 폴더를 따라가며 기능을 하나씩 확장하는 실습형 강의의 기준 저장소입니다.

## 버전별 학습 경로

| 폴더 | 목표 | 핵심 결과 |
| --- | --- | --- |
| [v0](v0/README.md) | RC카 주행 기반 만들기 | ESP32 + TB6612FNG로 전진·후진·좌·우·정지 |
| [v1](v1/README.md) | 거리 감지와 안전 기능 추가하기 | 전방 거리 측정, 경고·정지 판단 |
| [v2](v2/README.md) | 무선 조종기 만들기 | 조이스틱·버튼 명령을 차량으로 전송 |
| [v3](v3/README.md) | 핸드 제스처 조종으로 확장하기 | BMI270 기울기·동작을 조종 명령으로 변환 |

## 시작 방법

1. GitHub에서 `RC_CAR shinejihun1227`를 검색해 이 저장소를 찾습니다.
2. 항상 `v0`부터 시작합니다. 각 버전의 README, 문서, 펌웨어, 하드웨어 자료를 순서대로 읽습니다.
3. 버전이 완성되면 Commit을 남기고 다음 버전 폴더로 이동합니다.

## 라이선스와 안전

배터리와 모터를 연결할 때는 전원을 끈 상태에서 배선하고, ESP32와 모터 드라이버의 GND를 공통으로 연결합니다. 레이저는 사람이나 반사면을 향하지 않도록 저출력 모듈만 사용합니다.
