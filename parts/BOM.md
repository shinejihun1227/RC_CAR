# 전체 부품표

수량은 차량 1대와 조종기 1개 기준이다. v4의 '총 필요량'을 이전 버전 수량에 다시 더하지 않는다.

| 부품 | v0~v3 구성 | v4 최종 구성 | 설명 |
|---|---:|---:|---|
| ESP32 DevKit V1 | 차량 1개 + v2부터 조종기 1개 | 총 2개 | 차량·조종기 분리 |
| TT 모터·바퀴 | 각 2개 | 사용하지 않음 | 기초 2WD 실습 |
| 엔코더 N20 모터·호환 바퀴 | 없음 | 각 4개 | 문서 기준 6V 약 100RPM, 동일 옵션. 실물 사양 확인 |
| TB6612FNG | 1개 | 총 2개 | 모터당 독립 채널 |
| VL53L1X | v1부터 1개 | 1개 재사용 | 차량 전방 |
| 조이스틱 | v2 1개 | v2 조종기 선택 시 1개 | v3에서는 BMI270으로 입력 교체 |
| BMI270 | v3 1개 | v3 조종기 선택 시 1개 | 3.3V 호환 I²C 모듈 |
| 정지 버튼 | v2부터 1개 | 1개 재사용 | 속도 버튼은 기본 코드에 없음 |
| AA 알카라인 4개·홀더·스위치 | 1세트 | 1세트 | 차량 전원 |
| 5V 2A 이상 벅-부스트 | 1개 | 1개 | 선택한 부품의 입력 범위·출력 용량 확인 |
| 470µF 이상 전해 커패시터 | 1개 | 총 2개 | 드라이버 VM-GND 가까이에, 극성·정격 확인 |
| N20 브래킷 | 없음 | 4개 | 모터·엔코더 PCB와 간섭 확인 |
| 10kΩ 저항 | 필요에 따라 | 최대 4개 | 엔코더가 오픈 컬렉터일 때 CHA 풀업 |
| USB 케이블·보조배터리 | 조종기용 | 조종기용 | 조종기는 USB 5V 기준 |
| 배선·커넥터·M3 나사·스페이서 | 필요량 | 필요량 | 실제 장착홀과 전류에 맞춤 |

ESP32 핀에 5V 엔코더 출력을 직접 연결하지 않는다. 실제 엔코더 출력 방식·로직 전압, 모터 정지전류, 드라이버와 전원 용량을 확인한다. 부품명이나 외형이 같아도 판매 옵션에 따라 규격이 다를 수 있다.

제품 선정과 구매 URL 기록은 [단계별 구매 규격](README.md)을 사용한다.
