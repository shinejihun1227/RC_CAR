# 최종 차량과 조종기의 부품 원리

> 범위: 현재 저장소의 최종 목표인 **v4 4륜 엔코더 N20 RC카 + v3 BMI270 핸드 제스처 조종기**만 다룬다.
> TT 모터, 조이스틱, 초음파센서, 플렉스센서 등 현재 최종 구성에 사용하지 않는 부품은 포함하지 않는다.

---

## 전체 시스템과 전원

### 최종 시스템 구조

```text
손 조종기 ESP32 + BMI270 + 정지 버튼
                 │
                 │ ESP-NOW
                 ▼
차량 ESP32 ── VL53L1X 전방 거리센서
     │
     ├── TB6612FNG #1 ── 앞왼쪽 N20 / 앞오른쪽 N20
     └── TB6612FNG #2 ── 뒤왼쪽 N20 / 뒤오른쪽 N20
                              │
                         엔코더 펄스
                              ▼
                    차량 ESP32의 RPM·PID 보정
```

### 사용하는 부품과 역할

| 부품 | 수량 | 이 프로젝트에서의 역할 |
|---|---:|---|
| ESP32 DevKit V1 | 2 | 손 조종기 송신기 1개, 차량 제어기 1개 |
| BMI270 브레이크아웃 | 1 | 손의 기울기와 회전 측정 |
| VL53L1X ToF 센서 | 1 | 차량 전방 거리 측정과 안전 정지 |
| TB6612FNG | 2 | N20 모터 4개를 독립 PWM 제어 |
| 엔코더 포함 N20 메탈 기어드모터 | 4 | 감속·구동·회전 펄스 출력 |
| 3mm D축 호환 바퀴 | 4 | N20 출력축의 회전을 지면 이동으로 변환 |
| N20 금속 브래킷 | 4 | 모터를 3D 프린팅 샤시에 고정 |
| AA 알카라인 배터리 4개와 홀더 | 1세트 | 차량 모터와 전원 변환기의 입력 |
| 5V 2A 이상 벅-부스트 컨버터 | 1 | 차량 ESP32에 안정적인 5V 공급 |
| 470uF 이상 전해 커패시터 | 2 | 각 TB6612FNG의 모터 전원 노이즈 완화 |
| 10kΩ 저항 | 최대 4 | 오픈 컬렉터 엔코더 A 신호 풀업 |
| 정지 버튼·배선·커넥터·M3 체결부 | 필요량 | 비상정지, 연결, 조립 |

### 전원의 흐름

```text
AA 4개 약 6V
   ├── 스위치 ── TB6612FNG VM ── N20 모터 전원
   └── 5V 벅-부스트 ── 차량 ESP32 5V/VIN

차량 ESP32 3V3 ── TB6612FNG VCC
               ├─ VL53L1X 전원
               └─ 엔코더 로직 전원

모든 GND ─────── 공통 연결
```

전압은 부품에 맞춰야 하고, 전류 용량은 충분해야 한다. 모터가 출발할 때 큰 전류를 요구하면서 전원 전압이 흔들릴 수 있으므로 470uF 커패시터를 각 드라이버의 `VM-GND` 근처에 배치한다. 모터 전원은 ESP32 GPIO에서 가져오지 않는다.

### 강의 핵심 문장

> ESP32는 명령을 계산하고, TB6612FNG는 모터 전류를 스위칭하며, N20 모터는 실제 힘을 만든다. 센서와 모터의 전원 역할을 분리해야 안정적으로 동작한다.

## TB6612FNG·N20 모터·바퀴·엔코더

### TB6612FNG의 원리

TB6612FNG는 ESP32의 작은 GPIO 신호로 모터를 직접 구동하는 부품이 아니다. ESP32가 `IN1`, `IN2`, `PWM` 신호를 보내면 TB6612FNG 내부의 H-브리지 회로가 모터 전원 `VM`을 빠르게 스위칭한다.

| 입력 상태 | 모터 동작 |
|---|---|
| IN1=HIGH, IN2=LOW | 정방향 |
| IN1=LOW, IN2=HIGH | 역방향 |
| IN1=LOW, IN2=LOW | 정지 또는 coast |
| PWM의 듀티비 증가 | 평균 모터 전압과 속도 증가 |
| STBY=LOW | 드라이버 대기·출력 비활성 |
| STBY=HIGH | 드라이버 활성 |

현재 v4에서는 TB6612FNG 두 개의 네 채널을 모터 하나씩 사용한다. 모터 두 개를 한 채널에 병렬로 연결하지 않는다. 모터마다 기동전류와 마찰이 다르기 때문에 독립적으로 PWM과 PID를 조정해야 한다.

### N20 모터의 구조

```text
DC 모터의 빠른 회전
        ↓
금속 감속기: 속도 감소, 토크 증가
        ↓
3mm D축 출력축
        ↓
바퀴 회전과 차량 이동
```

N20의 모터 내부는 빠르게 회전하지만, 금속 기어가 회전수를 낮추고 출력 토크를 높인다. 따라서 모터의 RPM만 보고 바퀴 속도를 판단하면 안 된다. 감속비, 바퀴 지름, 실제 부하를 함께 봐야 한다.

### 홀 엔코더의 원리

모터 뒤쪽의 자석이 회전하고, 홀 센서가 자기장 변화를 감지한다.

```text
자석 회전 → 홀 센서 감지 → CHA/CHB 디지털 펄스 → ESP32 인터럽트
```

- 펄스의 개수: 얼마나 회전했는지
- 펄스가 발생한 시간: 얼마나 빠르게 회전하는지
- CHA와 CHB의 위상 차이: 회전 방향 판단

현재 v4 기본 코드는 `CHA`만 읽어 RPM을 측정하고, 회전 방향은 TB6612FNG에 보낸 모터 명령을 기준으로 판단한다. `CHB`는 기본 실습에서는 연결하지 않는다.

### RPM 계산

```text
RPM = 일정 시간 동안 센 펄스 수
      × 60
      ÷ (측정 시간(초) × 1회전당 펄스 수)
```

`PULSES_PER_WHEEL_REV`는 엔코더 제품의 감속비와 출력축 기준에 따라 달라지므로, 바퀴를 정확히 한 바퀴 돌려 실제 펄스 수를 측정해야 한다.

### PID 속도 보정

```text
목표 RPM
   ↓
오차 = 목표 RPM - 실제 RPM
   ↓
PID 계산
   ↓
TB6612FNG PWM 보정
   ↓
N20 모터 속도 변화
   ↓
엔코더가 다시 측정
```

### 강의 핵심 문장

> 모터의 PWM은 명령값이고, 엔코더 RPM은 결과값이다. PID는 두 값의 차이를 줄이는 피드백 제어다.

## VL53L1X 거리센서와 BMI270 IMU

### VL53L1X의 역할과 원리

VL53L1X는 차량 앞의 장애물까지 거리를 측정하는 ToF(Time of Flight) 센서다.

```text
적외선 펄스 발사 → 물체 반사 → 반사광 수신
                         ↓
                 빛의 왕복 시간 계산
                         ↓
                       거리(mm)
```

거리값을 반복 갱신하며, 전진 명령에서 `STOP_MM = 200` 이하이면 모터를 정지시킨다. 유효한 측정값이 없거나 250ms 넘게 갱신되지 않아도 전진을 차단한다. 후진·제자리 회전은 허용한다.

### VL53L1X 핀맵

| VL53L1X | 차량 ESP32 | 역할 |
|---|---:|---|
| VIN | 3.3V | 센서 전원 |
| GND | GND | 공통 접지 |
| SDA | GPIO21 | I²C 데이터 |
| SCL | GPIO22 | I²C 클록 |
| XSHUT | 미연결 | 센서 1개에서는 선택사항 |

센서는 차체 전면을 향하게 고정하고, 모터 전원선과 센서 배선을 가능한 한 떨어뜨린다.

### BMI270의 역할과 원리

BMI270은 손 조종기에 장착하는 6축 IMU다.

- 가속도계 3축: 중력과 직선 가속도 측정
- 자이로스코프 3축: X·Y·Z축 회전 속도 측정
- 가속도계의 중력 성분으로 Roll·Pitch 계산
- 계산된 기울기를 ESP-NOW 명령으로 변환

```text
손의 기울기
    ↓
BMI270 가속도 데이터
    ↓
Roll·Pitch 계산
    ↓
데드존 적용
    ↓
throttle·steering 명령 생성
    ↓
ESP-NOW로 차량 ESP32에 전송
```

### BMI270 핀맵

| BMI270 | 조종기 ESP32 | 역할 |
|---|---:|---|
| VIN | 3.3V | 센서 전원 |
| GND | GND | 공통 접지 |
| SDA | GPIO21 | I²C 데이터 |
| SCL | GPIO22 | I²C 클록 |
| INT1 | GPIO27 | 동작 인터럽트, 선택사항 |

현재 조종기 코드는 전원을 켤 때 100개의 가속도 샘플을 읽어 손의 중립 자세를 계산한다. 이후 `±8도`는 데드존으로 무시하고, 최대 약 `35도`까지 기울기를 PWM 명령 범위로 변환한다.

### 강의 핵심 문장

> VL53L1X는 차량 주변의 위험을 감지하고, BMI270은 운전자의 손동작을 감지한다. 하나는 차량 안전용이고, 다른 하나는 조종 입력용이다.

## 전체 핀맵과 실습 순서

### 차량 ESP32 최종 핀맵

| 위치 | TB6612FNG 채널 | IN1 | IN2 | PWM | 엔코더 CHA |
|---|---|---:|---:|---:|---:|
| 앞왼쪽 FL | #1 A | GPIO18 | GPIO19 | GPIO13 | GPIO34 |
| 앞오른쪽 FR | #1 B | GPIO23 | GPIO25 | GPIO14 | GPIO35 |
| 뒤왼쪽 RL | #2 A | GPIO26 | GPIO27 | GPIO16 | GPIO36 |
| 뒤오른쪽 RR | #2 B | GPIO32 | GPIO33 | GPIO17 | GPIO39 |

추가 연결:

```text
두 TB6612FNG STBY → ESP32 3.3V
두 TB6612FNG VCC  → ESP32 3.3V
VL53L1X SDA       → GPIO21
VL53L1X SCL       → GPIO22
```

GPIO 34, 35, 36, 39는 입력 전용이며 내부 풀업이 없다. 엔코더가 오픈 컬렉터 방식이면 각 `CHA` 신호와 3.3V 사이에 10kΩ 저항을 연결한다. 엔코더 출력이 5V라면 ESP32에 직접 연결하지 말고 3.3V 호환 여부를 확인한다.

### 조종기 ESP32 최종 핀맵

| 부품 | ESP32 |
|---|---:|
| BMI270 SDA | GPIO21 |
| BMI270 SCL | GPIO22 |
| BMI270 INT1 | GPIO27, 선택 |
| 정지 버튼 | GPIO4 |
| 버튼 반대쪽 | GND |

### 실습 진행 순서

1. `v3/firmware/00_bmi270_read`로 가속도·자이로 값을 확인한다.
2. `v1/firmware/01_distance_read`로 VL53L1X 거리값을 확인한다.
3. `v4/firmware/00_encoder_read`로 네 모터의 엔코더 펄스를 확인한다.
4. `v0/firmware/01_motor_test`로 TB6612FNG와 모터 방향을 확인한다.
5. `v4/firmware/01_speed_pid_tune`으로 목표 RPM과 실제 RPM을 비교한다.
6. `v3/firmware/controller_bmi270`으로 손 기울기 명령을 ESP-NOW로 전송한다.
7. `v4/firmware/vehicle_encoder_receiver`에서 거리 정지·ESP-NOW·PID를 통합한다.

### Python 실습의 범위

현재 센서는 ESP32의 I²C GPIO에 직접 연결되어 있고, 임베디드 펌웨어는 Arduino C++로 작성되어 있다. 따라서 PC의 Python이 ESP32 GPIO를 직접 읽는 방식이 아니라, **ESP32가 시리얼로 출력한 센서값을 Python이 읽고 계산·분석**하는 방식으로 구성한다.

Python 실습 파일은 다음 로그를 분석한다.

- BMI270: 가속도·자이로 → Roll·Pitch → 제스처 명령
- VL53L1X: 거리(mm) → 경고·정지 판정
- N20 엔코더: 펄스·RPM → 네 바퀴 속도 편차 확인
- TB6612FNG 모터 실습: 시리얼 명령으로 안전 정지 테스트

## 실습 안전 체크

- 배선 변경 전 AA 배터리 전원을 끈다.
- ESP32 GPIO에는 3.3V를 넘는 신호를 입력하지 않는다.
- TB6612FNG의 `VM`은 모터 전원, `VCC`는 로직 전원이다.
- 모터를 공중에 띄우고 방향·엔코더를 먼저 확인한다.
- 전진 명령에서 VL53L1X가 `200mm` 이하 장애물을 감지하면 정지해야 한다.
- ESP-NOW 통신이 300ms 이상 끊기면 차량을 정지시킨다.
