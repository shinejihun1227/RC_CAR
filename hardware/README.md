# 3D 하드웨어 파일 보관소

공통 3D 프린팅 자료를 이 폴더에서 관리합니다. 상세 설계 기준은 [프로젝트 통합 가이드](../docs/PROJECT_GUIDE.md)의 `3D 프린팅과 STL/CAD 관리`를 확인합니다.

```text
reference-models/  외부 참고 링크와 라이선스 메모
cad/               수정 가능한 원본 CAD
stl/               출력용 최종 STL
print-settings/    프린터·재료 설정
```

외부 STL은 모터 실측 치수와 라이선스를 확인한 뒤 추가합니다. 현재는 JGA12-N20 엔코더 모터의 실제 치수를 확정하기 전 단계입니다.
