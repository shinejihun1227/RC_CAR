# GitHub 조사 기록

강의에서는 검색 결과를 그대로 신뢰하지 않고 아래 기준으로 비교한다.

| 항목 | 확인 질문 |
| --- | --- |
| README | 목표와 부품 목록, 배선 정보가 있는가? |
| 코드 구조 | 모터 제어 핀과 명령 처리가 분리되어 있는가? |
| 안전성 | 모터를 GPIO에 직접 연결하지 않았는가? |
| 재현성 | 보드 종류, 라이브러리, 실행 절차가 명확한가? |
| 확장성 | 센서와 통신 기능을 추가할 여지가 있는가? |
