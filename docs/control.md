# 제어 구조와 코드 동작

## 신호 흐름

```text
조이스틱(추가 시) 또는 Uno 시리얼 입력
      → Uno: 전진·회전 명령 생성
      → nRF24L01 무선 송신
      → Mega: 유효한 명령 수신
          + VL53L0X: 앞쪽 거리 측정
      → 좌·우 모터 명령 계산
      → L298N 방향(IN1~IN4)과 PWM(ENA/ENB)
      → 두 바퀴
```

VL53L0X는 **차량 전방 장애물 거리**를 측정하는 센서입니다. nRF24L01은 센서가 아니라 **송수신기**입니다. L298N은 센서가 아니라 Mega의 작은 제어 신호로 모터 전류의 방향과 크기를 바꾸는 **구동기**입니다. 거리 센서는 I²C(SDA/SCL), 무선 모듈은 SPI(MISO/MOSI/SCK + CE/CSN)를 사용합니다. [ST VL53L0X](https://www.st.com/en/product/vl53l0x), [RF24 Arduino 배선](https://github.com/nRF24/RF24/blob/master/docs/arduino.md)

## 조종 명령과 좌우 바퀴 혼합

조종기는 `throttle`(전진 + / 후진 −)과 `steering`(오른쪽 + / 왼쪽 −)을 각각 **−100~100**으로 보냅니다. Mega는 아래처럼 두 바퀴 명령을 만듭니다.

```text
왼쪽 = throttle + steering
오른쪽 = throttle - steering
```

두 값 중 절댓값이 100을 넘으면 **같은 비율로 100 이하로 축소**합니다. `+`는 그 바퀴의 전진, `−`는 후진으로 정의하고, 물리적인 모터 장착 방향은 `LEFT_MOTOR_INVERTED` / `RIGHT_MOTOR_INVERTED`로 보정합니다. 바퀴 인코더가 없으므로 PWM은 **목표 출력**이지 실제 RPM 피드백이 아닙니다. 이 구성만으로 정확한 속도·이동 거리 제어는 할 수 없습니다.

## 거리 제한

- 센서가 **300 mm 이하**를 읽으면 각 바퀴의 **양수(전진) 명령을 0으로 제한**합니다. 후진 명령은 허용해 장애물에서 빠져나올 수 있게 합니다.
- 센서가 **400 mm 이상**을 읽으면 전진을 다시 허용합니다. 300~400 mm 사이의 이전 상태를 유지하는 **히스테리시스**로 경계에서 덜컥거림을 줄입니다.
- 센서 초기화 실패, 읽기 시간 초과, 0 또는 65535 mm 값은 **전진 금지**로 처리합니다.
- 이 숫자는 실제 차의 **속도·무게·바닥 마찰·제동 거리**를 측정해 바꿔야 합니다. 센서가 모든 재질과 각도의 장애물을 확실히 볼 수 있는 것은 아니므로 충돌 방지의 유일한 수단으로 간주하지 마세요.

## 무선 패킷과 끊김 정지

송신기와 수신기 모두 같은 **5바이트 구조**를 씁니다.

| 바이트 | 이름 | 뜻 |
|---:|---|---|
| 0 | `magic` | 고정값 `0xA5` |
| 1 | `vehicleId` | 차량 번호 1~16 |
| 2 | `throttle` | 부호 있는 −100~100 |
| 3 | `steering` | 부호 있는 −100~100 |
| 4 | `sequence` | 전송할 때마다 증가하는 값(진단용) |

양쪽 코드의 `VEHICLE_ID`, `RADIO_CHANNEL`, 패킷 구조, RF 설정이 같아야 합니다. 첫 시험 기본값은 `VEHICLE_ID=1`, `RADIO_CHANNEL=76`, 250 kbps, 자동 수신 확인, 16비트 CRC입니다. 조종기는 **50 ms마다** 패킷을 보냅니다. Mega는 마지막 **유효한 패킷 이후 300 ms**가 지나면 두 모터를 0으로 만듭니다. 시리얼 입력 모드에서 `w/s/a/d/q/e/z/c` 한 번은 **800 ms만 유지**되고 자동 정지합니다. 조이스틱 모드에서는 매번 현재 위치를 다시 읽습니다. [RF24 라이브러리](https://github.com/nRF24/RF24), [일치해야 하는 RF 설정](https://github.com/nRF24/RF24/blob/master/COMMON_ISSUES.md)

## 15대 + 로봇팔 1대 확장

차량 16대 각각 `VEHICLE_ID=1..16`을 지정하고, 해당 조종기에도 같은 번호를 지정합니다. 코드의 5바이트 무선 주소가 이 번호에서 생성됩니다. 여러 조종기가 동시에 작동할 계획이면 **채널도 짝마다 계획**하고 실제 장소에서 간섭·지연·오작동을 시험해야 합니다. 현재의 단일 차량 실험 코드를 16대 동시 운용 검증 완료로 보아서는 안 됩니다. 로봇팔 1대의 서보 전원과 제어 명령은 별도 단계에서 추가해야 합니다.
