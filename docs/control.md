# 차량이 움직이는 방식

> 아래는 이전 코드의 제어 설명입니다. 현재 v0~v4 실습은 [v0~v4 실습 안내](v0-v4-practice.md)를 기준으로 확인하세요.

리모컨 Uno는 KCD1의 위치에 따라 **1번 조이스틱** 또는 **BMI270 기울기**로 전진·회전 값을 만듭니다. 이를 무선으로 보내면 차량 Mega가 두 모터의 명령으로 바꿉니다. Mega는 동시에 VL53L0X로 앞쪽 거리를 읽습니다. 가까운 장애물이 있으면 전진 출력을 막고, 무선 명령이 끊기면 두 모터를 정지시킵니다. 2번 조이스틱과 두 `SW` 버튼은 현재 주행 명령에 사용하지 않습니다.

```text
조이스틱 1 ─┐
           ├─ KCD1 모드 선택 → Uno → 무선 모듈 → Mega ← 거리 센서
BMI270 ────┘                                      ↓
                                           L298N → 모터 2개
```

## 좌우 바퀴 계산

조종기 코드는 `throttle`(전진·후진)과 `steering`(좌·우 회전)을 각각 -100부터 100까지 보냅니다. 차량 코드는 다음 식으로 좌우 출력을 정합니다.

```text
왼쪽 바퀴 = throttle + steering
오른쪽 바퀴 = throttle - steering
```

값이 100을 넘으면 두 바퀴의 비율을 유지하면서 범위 안으로 줄입니다. L298N의 `IN1~IN4`가 방향을, `ENA/ENB`의 PWM이 출력 정도를 정합니다. 바퀴 회전수를 읽는 엔코더는 현재 구성에 없으므로, PWM 값을 줘도 실제 RPM을 알 수는 없습니다. [L298N 동작 설명](https://docs.sunfounder.com/projects/sf-components/en/latest/component_l298n_module.html)

## 거리와 무선 연결

기본 설정은 앞쪽 물체가 **30 cm 이내**이면 각 바퀴의 전진 명령을 0으로 만드는 것입니다. 후진은 허용합니다. 물체가 **40 cm 밖**으로 나가면 전진을 다시 허용합니다. 30~40 cm 구간에서는 이전 상태를 유지해 경계에서 바퀴가 계속 켜졌다 꺼지는 일을 줄입니다. 센서 초기화나 거리 읽기에 실패했을 때도 전진을 막습니다.

조종기는 50 ms마다 명령을 보내고, Mega는 마지막 유효 명령 이후 300 ms가 지나면 정지합니다. 시리얼 조종 명령 한 번은 800 ms만 유지됩니다. 이 수치와 정지 거리는 첫 주행에서 차의 속도와 바닥 상태를 보고 조정합니다.

## KCD1 모드와 BMI270

KCD1의 `D4-GND` 접점이 열려 있으면 조이스틱 모드, 닫혀 있으면 기울기 모드입니다. 모드를 바꾸면 명령을 0으로 만들고, 조이스틱은 중앙을 한 번 통과해야 움직입니다. 기울기 모드에서는 전환 직후 BMI270의 X/Y 가속도를 기준 자세로 저장합니다. 그 뒤 기준에서 얼마나 기울었는지를 전진·회전 값으로 바꿉니다. 작은 흔들림(0.08 g 이내)은 무시하고, 약 0.55 g 변화에서 최대 명령이 됩니다. 기판 설치 방향에 따라 `TILT_THROTTLE_SIGN`과 `TILT_STEERING_SIGN`을 조정합니다. BMI270 초기화나 읽기가 실패하면 기울기 모드에서는 0 명령을 보냅니다.

## 조종기와 차량 짝 맞추기

두 코드에 같은 `VEHICLE_ID`와 `RADIO_CHANNEL`을 넣습니다. 기본값은 차량 번호 `1`, 채널 `76`입니다. 전송 내용은 차량 번호, 전진 값, 회전 값, 순서 번호 등이 들어 있는 5바이트 패킷입니다. 두 모듈의 무선 설정이 같아야 통신됩니다. [RF24 설정 안내](https://github.com/nRF24/RF24/blob/master/COMMON_ISSUES.md)

16대를 만들 때는 차량마다 `VEHICLE_ID`를 1~16으로 다르게 지정합니다. 여러 조종기를 한 장소에서 동시에 켠다면 채널 배치와 간섭을 현장에서 확인해야 합니다. 로봇팔용 서보 명령은 주행 기능을 먼저 완성한 뒤 추가합니다.
