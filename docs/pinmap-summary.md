# RC카 v0~v4 핀맵 요약

| 구성 | 보드 | 전원 | 역할 |
|---|---|---|---|
| 차량 | Arduino Mega 2560 | 12V 어댑터 → LM2596 5.0V → Mega `5V`·`GND` (단독 주행 시, USB 분리) | 모터·거리센서·무선 수신 제어 |
| 조종기 | Arduino Uno | PC USB | 조이스틱·스위치·BMI270·무선 송신 제어 |
| 차량 ↔ 조종기 | 무선 통신 | 전원선·GND선 서로 연결 안 함 | nRF24L01+ 2개로 통신 |

## 차량 전원: 12V 어댑터·LM2596·L298N·Mega

| 출발 핀/선 | 도착 핀/선 | 조건·역할 |
|---|---|---|
| 12V 5A 어댑터 `+` | L298N `12V`, LM2596 `IN+` | 12V 병렬 분기; 모터 정격 전압 확인 |
| 12V 5A 어댑터 `−` | L298N `GND`, LM2596 `IN−` | 공통 전원 귀로 |
| LM2596 `OUT+` | Mega `5V` | **무부하 출력 5.0V 측정 후** 연결; PC USB와 동시 공급 금지 |
| LM2596 `OUT−` | Mega `GND` | 강압 출력 접지 |
| Mega `GND` | L298N `GND` | 제어 신호의 공통 기준 |
| L298N `5V-EN` 점퍼 | 장착 | 이 12V 구동 구성에서 모듈의 5V 레귤레이터를 사용; 실물 레귤레이터·발열 확인 |
| L298N `5V` 나사 단자 | Mega `5V`에 연결 **안 함** | `5V-EN` 장착 시 모듈 내부 논리 전원의 5V 출력 |
| L298N `ENA`·`ENB` 점퍼 | 제거 | Mega의 PWM 속도 제어선을 꽂기 위해 제거 |
| Mega USB | 업로드 때만 PC 연결 | 업로드·USB 실습 때는 LM2596→Mega `5V` 전원 분리 |

## 차량 구동: Mega ↔ L298N ↔ 모터

| Mega 핀 | L298N 핀 | 연결 대상·역할 | 사용 버전 |
|---|---|---|---|
| `D5` (PWM) | `ENA` | 왼쪽 모터 A 속도 | v0~v4 |
| `D22` | `IN1` | 왼쪽 모터 A 방향 1 | v0~v4 |
| `D23` | `IN2` | 왼쪽 모터 A 방향 2 | v0~v4 |
| `D24` | `IN3` | 오른쪽 모터 B 방향 1 | v0~v4 |
| `D25` | `IN4` | 오른쪽 모터 B 방향 2 | v0~v4 |
| `D6` (PWM) | `ENB` | 오른쪽 모터 B 속도 | v0~v4 |
| — | `OUT1` | 왼쪽 모터 `+` 표시선; 실제 전진 방향 확인 | v0~v4 |
| — | `OUT2` | 왼쪽 모터 `−` 표시선; 실제 전진 방향 확인 | v0~v4 |
| — | `OUT3` | 오른쪽 모터 `+` 표시선; 실제 전진 방향 확인 | v0~v4 |
| — | `OUT4` | 오른쪽 모터 `−` 표시선; 실제 전진 방향 확인 | v0~v4 |
| `GND` | `GND` | 공통 접지 | v0~v4 |

## 차량 거리센서: VL53L0XV2 ↔ Mega

| 센서 기판 핀 | Mega 핀 | 조건·역할 | 사용 버전 |
|---|---|---|---|
| `VIN`/`VCC` | `5V` 또는 규정된 `3.3V` | **센서 기판의 입력 허용 전압에 맞춤**; 3.3V 전용 기판에 5V 금지 | v1~v4 |
| `GND` | `GND` | 공통 접지 | v1~v4 |
| `SDA` | `D20` (SDA) | I²C 데이터; 3.3V 전용 기판은 신호 전압 변환 확인 | v1~v4 |
| `SCL` | `D21` (SCL) | I²C 클록; 3.3V 전용 기판은 신호 전압 변환 확인 | v1~v4 |
| `XSHUT` | 연결 안 함 | 현재 코드에서 미사용 | — |
| `GPIO1`/`INT` | 연결 안 함 | 현재 코드에서 미사용 | — |

## 무선 본체: nRF24L01+ PA/LNA 1개 ↔ Mega, 1개 ↔ Uno

| 무선 본체 핀 | 차량 Mega | 조종기 Uno | 역할·전압 | 사용 버전 |
|---|---|---|---|---|
| `GND` | 공통 `GND` | Uno `GND` | 무선 전원·신호 접지 | v2~v4 |
| `VCC` | 별도 안정된 `3.3V` 출력 | 별도 안정된 `3.3V` 출력 | **맨 무선 본체에 5V 금지**; PA/LNA형 전류를 공급할 수 있는 3.3V 전원 사용 | v2~v4 |
| `CE` | `D7` → 3.3V 신호 변환 → `CE` | `D7` → 3.3V 신호 변환 → `CE` | 송수신 동작 제어 | v2~v4 |
| `CSN`/`CS` | `D8` → 3.3V 신호 변환 → `CSN` | `D8` → 3.3V 신호 변환 → `CSN` | SPI 선택 | v2~v4 |
| `SCK` | `D52` → 3.3V 신호 변환 → `SCK` | `D13` → 3.3V 신호 변환 → `SCK` | SPI 클록 | v2~v4 |
| `MOSI` | `D51` → 3.3V 신호 변환 → `MOSI` | `D11` → 3.3V 신호 변환 → `MOSI` | Arduino → 무선 데이터 | v2~v4 |
| `MISO` | `D50` | `D12` | 무선 → Arduino 데이터 | v2~v4 |
| `IRQ` | 연결 안 함 | 연결 안 함 | 현재 코드에서 미사용 | — |
| Arduino SPI 마스터 `SS` | `D53` 출력 설정, 무선에는 연결 안 함 | `D10` 출력 설정, 무선에는 연결 안 함 | 코드에서 SPI 마스터 상태 유지 | v2~v4 |

| 조이스틱 | 조이스틱 핀 | Uno 핀 | 현재 코드의 기능 | 사용 버전 |
|---|---|---|---|---|
| 왼쪽 | `GND` | `GND` | 공통 접지 | v3~v4 |
| 왼쪽 | `5V` | `5V` | 조이스틱 전원 | v3~v4 |
| 왼쪽 | `VRx` | `A0` | **전진·후진**; 중앙 약 512 | v3~v4 |
| 왼쪽 | `VRy` | `A1` | 연결 가능, 주행 코드에서 미사용 | — |
| 왼쪽 | `SW` | `D2` | 누름 버튼; 주행 코드에서 미사용 | — |
| 오른쪽 | `GND` | `GND` | 공통 접지 | v3~v4 |
| 오른쪽 | `5V` | `5V` | 조이스틱 전원 | v3~v4 |
| 오른쪽 | `VRx` | `A2` | 연결 가능, 주행 코드에서 미사용 | — |

## 조종기 모드 선택: KCD1 ↔ Uno

| KCD1 접점/상태 | Uno 핀 | 코드 동작 | 사용 버전 |
|---|---|---|---|
| 도통되는 접점 한쪽 | `D4` (`INPUT_PULLUP`) | 모드 입력 | v4 |
| 도통되는 접점 다른 쪽 | `GND` | 접점을 닫으면 `D4=LOW` | v4 |
| 접점 열림 | `D4=HIGH` | 조이스틱 모드 `JOY` | v4 |
| 접점 닫힘 | `D4=LOW` | BMI270 기울기 모드 `TILT` | v4 |

## 조종기 기울기 입력: BMI270 ↔ Uno

| BMI270 기판 핀 | Uno 핀 | 조건·역할 | 사용 버전 |
|---|---|---|---|
| `VIN`/`VCC` | 기판이 5V 입력형이면 `5V`; 3.3V 전용이면 규정된 `3.3V` | **기판 사양 확인 후 선택**; BMI270 원칩에 5V 금지 | v4 |
| `GND` | `GND` | 공통 접지 | v4 |
| `SDA` | `A4` (SDA) | I²C 데이터; 3.3V 전용 기판이면 양방향 I²C 레벨 변환 | v4 |
| `SCL` | `A5` (SCL) | I²C 클록; 3.3V 전용 기판이면 양방향 I²C 레벨 변환 | v4 |
| `CS`/`CSB` | 기판별 I²C 선택 배선 | 기판에서 I²C가 기본 설정이면 추가 연결 없음 | 기판별 |
| `SDO`/`SA0` | 기판별 주소 선택 배선 | 코드가 `0x68`, 실패하면 `0x69` 순서로 탐색 | 기판별 |
| `INT1`/`INT2` | 연결 안 함 | 현재 코드에서 미사용 | — |
