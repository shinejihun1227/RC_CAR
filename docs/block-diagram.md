# RC Car v0 블록 다이어그램

```text
              2S 리튬전지팩
                    |
          +---------+----------+
          |                    |
      5 V 벅 컨버터        3.3 V 벅 컨버터
          |                    |
     TB6612FNG            ESP32 개발보드
       |     |              |\
   좌 모터  우 모터     GPIO ─┘ \n+                         |
                    Wi-Fi 제어(다음 단계)
```

## 제어 흐름

```text
사용자 명령 → ESP32 → TB6612FNG → 좌·우 모터 → RC카 이동
```

ESP32와 TB6612FNG의 GND는 반드시 공통으로 연결한다.
