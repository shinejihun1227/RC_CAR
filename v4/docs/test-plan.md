# v4 테스트 계획

1. 전원을 넣기 전 모든 엔코더 신호가 3.3 V 이하인지 확인한다.
2. `00_encoder_read`에서 각 바퀴를 손으로 돌려 해당 채널 펄스만 증가하는지 확인한다.
3. 네 모터를 차례로 구동해 방향과 RPM 출력을 확인한다.
4. `01_speed_pid_tune`에서 네 목표 RPM의 편차를 기록하고 PID·trim을 조정한다.
5. 바닥에서 1 m 직진을 3회 반복해 좌우 편차를 기록한다.
6. v2 또는 v3 조종기로 주행 중 거리 정지와 통신 끊김 정지를 확인한다.


## 전진 감시 추가 시험

- 201mm, 200mm, 199mm 부근에서 전진 허용·차단을 확인한다. 센서 오차가 있으므로 실제 출력값도 기록한다.
- 주행 중 센서 갱신이 끊기면 전진이 차단되는지 확인한다.
- 가까운 장애물에서 후진·제자리 회전이 가능한지 확인한다.
