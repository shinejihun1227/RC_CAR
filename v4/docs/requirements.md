# v4 요구사항

- 차량은 6 V, 100 RPM급 엔코더 포함 N20 메탈 기어드모터 2개와 자유회전 수동 바퀴 2개를 사용한다.
- 좌우 N20 모터는 TB6612FNG 한 개의 A/B 채널에 각각 연결한다.
- 각 구동 모터는 엔코더 A 채널 1개로 속도를 측정한다. 방향은 모터 명령에서 알 수 있으므로 첫 실습에서는 B 채널을 연결하지 않는다.
- 좌우 2개의 구동 모터 속도를 각각 PID로 제어한다. 수동 바퀴는 속도 피드백 대상이 아니다.
- v1의 거리 안전 정지와 v2의 통신 끊김 자동 정지는 최우선으로 동작한다.
