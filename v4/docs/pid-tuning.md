# PID 튜닝 순서

1. 차체를 받침대에 올려 네 바퀴가 바닥에서 떨어지게 한다.
2. `00_encoder_read`에서 모터를 한 바퀴 돌려 `PULSES_PER_WHEEL_REV`를 측정한다.
3. `01_speed_pid_tune`에서 `f`를 보내고 네 RPM이 출력되는지 확인한다.
4. 먼저 `Kp`만 조금씩 높여 목표 RPM에 빨리 도달하게 한다.
5. 목표보다 계속 느리거나 빠른 편차가 남으면 `Ki`를 아주 작게 올린다.
6. 진동하거나 PWM이 계속 크게 오르내리면 `Kp` 또는 `Ki`를 낮춘다.
7. 바닥 주행에서 직진 편차가 남으면 모터별 `trim` 값을 0.02씩 조정한다.

처음에는 낮은 목표 RPM으로 시작하고, 모터 발열·배터리 전압·드라이버 발열을 확인한 뒤 속도를 올립니다.
